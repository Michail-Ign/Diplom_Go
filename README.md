# Файлы для итогового задания

Данные проект демонстрирует работы с несколькими фрейворками:
работа SQLLite
работа с http
работа с jwt-шифрованием

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Выполнены задачи со свездочкой:
урок2 - Приступаем к дипломному проекту
урок3 - Проектируем и создаем БД
урок4 - Правила повторения
урок6 - Получаем список ближайших задач
урок8 - завешаем реализацию API
